# Focus Study Clock — Generative Background Layer (Product Writeup)

## What Changed

This update introduces a client-side generative art background layer (`InfiniteShaderBackground`) that renders live abstract canvas art using WebGL2 fragment shaders. It is built entirely on non-diffusion, code-driven techniques (fBm noise, domain warp, phyllotaxis / sunflower spiral). No images are downloaded. No server-side secrets are needed. The background lives behind every tab of the app (focus, clock, tasks, journal, settings) because it is mounted at the root level in `App.tsx`.

## Technical Approach

- **Shader-first architecture:** A single full-screen `<canvas>` (`fixed inset-0 -z-10`) renders a GLSL fragment shader directly to the GPU (`WebGL2`, `low-power` preference, capped at 1.5 DPR).
- **No diffusion models:** All art is generated by mathematical functions — fractal Brownian motion (`fbm`), domain warping (`domainWarp` from Inigo Quilez's technique), and phyllotaxis (Fibonacci/golden-angle sunflower spirals from agent 7's procedural-math catalog).
- **Infinite / non-repeating:** Each user session generates a new random `seed` (`sessionSeedRef`). The shader uses `u_time` + `u_seed` as uniforms, making every design unique. No memory of previous designs exists unless the user explicitly stars one.
- **Favourite / replay system:** The user clicks `★ Star` to save the current `{mode, seed}` variables (not an image) to `localStorage` (`shader_favourites`). Replay buttons (`◈` for fBm, `🌻` for phyllotaxis) restore the saved seed, remaking the exact same abstract design from its variables.
- **Accessibility:** The shader pauses when the tab is hidden (`visibilitychange`), freezes to a single static frame under `prefers-reduced-motion`, and uses `aria-hidden="true"` + `pointer-events-none` so it never interferes with the UI.

## Modes (Toggle at Top-Right)

| Mode | Description | Key Visual |
|---|---|---|
| `fbm` (default) | Double-warped fractal noise (`fbm` + `domainWarp`) with very slow time scroll; dark muted teal/amber tones; calm abstract depth. | Slow-moving abstract nebula texture |
| `phyllotaxis` | Sunflower / Fibonacci spiral (`goldenAngle`, `sqrt(i)` radius, 350 dots); geometric organic calm; rotates gently over time. | Golden spiral pattern of dots |

## How to Use

- The toggle (`Shader: fBm` / `Shader: Sunflower`) is visible in the top-right corner of any tab.
- Click to switch modes instantly — the shader recompiles/reuses the same WebGL context and redraws.
- Click `★ Star` to save the current design variables. Replay via the small buttons that appear below.
- Refreshing the page creates a brand-new random design (new `seed`). The previous design is forgotten unless it was starred.

## Integration in App

- Component: `src/components/InfiniteShaderBackground.tsx`
- Integration point: `src/App.tsx` (mounted before `SceneBackground`, behind all content)
- Settings / scenes: `src/lib/scenes.ts` defines 7 ambience scenes (`rainy-window`, `quiet-meadow`, `forest-grove`, `cozy-library`, `snowfall-dusk`, `seaside-cliff`, plus the shader layer which acts as an independent abstract scene). The shader coexists with the ambience system — turning ambience off does not disable the shader (it is independent), ensuring the abstract art is always present.

## Architecture Summary

- No server backend needed for the shader.
- No image assets or binary downloads.
- Client-side only: React component + WebGL2 + GLSL strings.
- Variables stored in `localStorage` for favourites; replay rebuilds art from code.
- Dark premium theme preserved (`bg-black` parent + shader's muted palette).
- All tabs covered because the shader is mounted at the app root (`App.tsx`) rather than inside individual tab components.

## What the User Sees

When opening the app:
1. A calm abstract dark background renders (either `fbm` or `phyllotaxis` depending on the last mode or toggle).
2. A floating toggle at the top-right shows the active mode (`Shader: fBm` or `Shader: Sunflower`).
3. The `★ Star` button allows saving the current variables.
4. Replay buttons appear below the star when favourites exist, allowing instant restoration of saved abstract designs.
5. All 7 ambience scenes + shader layer are available; the shader acts as an additional abstract scene option beyond the 6 gradient-based scenes.
